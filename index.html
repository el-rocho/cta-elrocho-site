Tres piezas, dos formas de uso

Elige según tu forma de trabajar

La versión individual funciona por sí sola. Para varias personas combina el servidor autoalojado con la aplicación cliente.

01 · La opción sencilla

Individual offline

Para una persona que quiere empezar sin cuentas, sin servidor y sin conexión.

  • Los datos permanecen en el dispositivo
  • Aplicación Android y PWA instalable
  • Historial, gráficas, estadísticas e informes
  • Copias completas y exportación PDF/CSV
Probar en el navegador Descargar APK →

Las mediciones se guardan únicamente en el navegador. Crea una copia para cambiar de dispositivo.

02 + 03 · La opción compartida

Tu servidor, tus usuarios

Una instalación privada centraliza las cuentas y mediciones. Cada persona accede desde el navegador o desde su aplicación cliente.

Servidor

Autoalojado

Servidor multiusuario con Docker, SQLite, administración familiar y autenticación 2FA.

  • Datos en tu servidor o NAS
  • Cuentas independientes
  • Copias de toda la instalación
Ver instalación →
Aplicación

Cliente Android y PWA

La interfaz móvil para conectarse de forma segura a una instalación autoalojada existente.

  • Conexión mediante HTTPS
  • Android, teléfono y tableta
  • Experiencia completa de la aplicación
Abrir cliente PWA → APK

Para probar el cliente debes tener una instalación autoalojada en ejecución y conocer su dirección HTTPS.
