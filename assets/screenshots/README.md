# Capturas publicadas

Imágenes utilizadas por la portada:

1. `offline-nueva-medicion.png`: formulario de la edición individual offline.
2. `offline-evolucion-anual.png`: gráfica de evolución de la edición individual.
3. `servidor-nueva-medicion.png`: formulario de la edición con servidor autoalojado.

Recomendaciones:

- usar datos de demostración, nunca datos personales;
- formato PNG o WebP;
- mínimo 1200 px en el lado largo;
- tema claro preferentemente, o aportar también variantes oscuras;
- ocultar barra de direcciones, notificaciones e identificadores del dispositivo.
