# Capturas pendientes

El diseño reserva dos composiciones:

1. `individual.webp`: vista vertical de la edición individual.
2. `servidor.webp` y `cliente.webp`: escritorio del servidor y vista móvil del cliente.

Recomendaciones:

- usar datos de demostración, nunca datos personales;
- formato PNG o WebP;
- mínimo 1200 px en el lado largo;
- tema claro preferentemente, o aportar también variantes oscuras;
- ocultar barra de direcciones, notificaciones e identificadores del dispositivo.
